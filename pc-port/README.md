# pc-port: тестовая сцена Windows с режимами 30 / 60 / без лимита

> Это **не** GTA VI. Игру запустить не удалось: в рабочей папке нет игровых
> файлов, разрешённых для портирования (см. `docs/COMPATIBILITY.md`).
> Здесь собственная тестовая сцена и общий код: игровой цикл, ограничитель
> кадров, замер времени кадра.

## Сборка

Linux, кросс-сборка под Windows x64 (как в этом репозитории):

    ./build.sh --test

Полный лог сборки пишется в `results/build_log.txt`.

Windows 11 x64 (Visual Studio 2022 и CMake):

    powershell -ExecutionPolicy Bypass -File build.ps1

## Запуск тестовой сцены (Windows)

    powershell -ExecutionPolicy Bypass -File run.ps1

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Ходьба; в машине W/S — газ и тормоз, A/D — руль |
| Shift | Бег |
| Tab / E (геймпад: Y) | Сесть в машину / выйти |
| F1 / F2 / F3 | Лимит 30 / 60 / без лимита |
| Esc | Выход |

Геймпад: левый стик — движение и руль, RT/LT — газ и тормоз, A — бег.

Бенчмарк сцены по маршруту: три прогона по 60 с для каждого режима, результаты в `results\bench_windows.txt` и CSV:

    powershell -ExecutionPolicy Bypass -File run.ps1 -Bench

## Тест независимости от FPS

    build/linux/pcport_tests            # полный: 3 прогона по 60 с на реальных часах
    build/linux/pcport_tests --quick    # быстрый: 5 с на реальных часах
    build\win64\pcport_tests.exe        # то же на Windows

| Тест | Что проверяет |
|---|---|
| T1 | 60 с симуляции на виртуальных часах: 30 FPS, 60 FPS, без лимита, рывки по 120 мс, GPU-bound 45 мс. Финальное состояние должно совпасть бит-в-бит: позиции, дистанции, таймер миссии, фаза анимации, аудиособытия |
| T2 | Контрольный опыт: та же физика с переменным dt должна расходиться. Это доказывает, что сравнение в T1 и T3 чувствительное |
| T3 | Реальные часы, раздельные потоки симуляции и отрисовки, 60 с на каждый режим. Результат должен совпасть, симуляция — идти в реальном времени |
| T4 | Живой ввод записывается при 60 FPS и повторяется при 30 FPS и без лимита — состояние должно совпасть |

## Устройство

| Путь | Содержимое |
|---|---|
| `src/core/sim.*` | Детерминированная симуляция, 120 Гц: персонаж, машина, таймер миссии, анимация, аудиособытия на часах 48 кГц |
| `src/core/loop.*` | `runThreaded` — отдельный поток симуляции и рендер с интерполяцией; `runSingleThread` — аккумулятор для тестов |
| `src/core/frame_limiter.*` | Лимит 30 / 60 / без лимита по абсолютным дедлайнам |
| `src/core/clock.*` | Реальные часы: QPC и high-res waitable timer на Windows, clock_gettime на POSIX; виртуальные часы для тестов |
| `src/core/frame_stats.*` | Среднее FPS, 1% low, p50/p99, CSV |
| `src/platform/win32/` | Окно, D3D11, ввод, GPU-таймеры |
| `src/tools/inventory_main.cpp` | Инвентаризация материалов только на чтение |
